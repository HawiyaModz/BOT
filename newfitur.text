Metode:
- Membandingkan fungsi/kode plugin, bukan hanya nama file atau command.
- Fitur dengan fungsi setara di Rimuru tidak disalin.
- Alias/command yang bentrok tidak digunakan.
- Dependency lokal dan asset yang dibutuhkan ikut dibawa bila belum tersedia.
- API untuk fitur impor disimpan di rimuru.js melalui RIMURU_ZERO_API; config.js hanya mereferensikan object tersebut.
